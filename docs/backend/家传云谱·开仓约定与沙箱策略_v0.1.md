## 1. 外部依赖沙箱策略（负责人默认）

在未指定专人之前，**默认负责人 = 后端研发（本地/CI 自管）**。接入真实云账号时再在下表「生产负责人」列补人名。

| 依赖 | 本地 / CI（默认） | 预发 / 生产 | 默认负责人 | 说明 |
|------|-------------------|-------------|------------|------|
| 对象存储 | **MinIO**（Docker） | 阿里云 OSS | 研发自管 | 桶名、公钥仅走环境变量；禁止提交密钥 |
| 短信验证码 | **Mock**：固定码或日志打印（如 `123456`，仅 `local`/`dev`） | 阿里云短信等 | 研发自管 | 生产关闭 Mock；限流仍生效 |
| 支付 | **Mock 支付**：下单后管理接口或延时消息模拟成功回调 | 微信/支付宝沙箱 → 正式 | 研发自管 | 回调验签逻辑本地用测试密钥；状态机不变 |
| MySQL / Redis / RabbitMQ | Docker Compose | 云托管或自建 | 研发自管 | 见 §3 Compose 服务名约定 |

**原则**：业务代码只依赖接口（`SmsSender` / `PaymentClient` / `ObjectStorage`），用 Spring Profile 切换实现；**禁止**在 `local` 误连生产支付。

## 2. 仓库约定（开仓时照抄）

### 2.1 位置与命名

- 路径（本 monorepo）：`jcyunpu/backend/`（单模块 `jcyunpu-server`）  
- 或独立仓：`jcyunpu-server`（需同步拷贝 `docs/backend` 引用说明）  
- **默认选 monorepo 的 `backend/`**，减少前后端文档分叉。

### 2.2 目录结构（首期）

```
backend/
  README.md
  pom.xml
  .env.example
  docker-compose.yml          # MySQL Redis RabbitMQ MinIO
  src/main/java/com/jcyunpu/
    JcyunpuApplication.java
    common/                   # 响应、异常、租户上下文
    auth/ / user/ / tenant/
    genealogy/ / member/ / collaborator/
    person/ / relationship/
    subscription/ / order/ / quota/
    ...（按架构 §3.1 扩展）
  src/main/resources/
    application.yml
    application-local.yml
    db/migration/             # Flyway
  src/test/
```

### 2.3 分支

| 分支 | 用途 |
|------|------|
| `main` | 可发布；受保护 |
| `develop`（可选） | 集成 |
| `feature/*` | 特性 |
| `fix/*` | 缺陷 |

开仓首提交：骨架 + Flyway 空/基线 + Compose + README，**不**塞业务 Controller 空壳之外的假实现冒充完成。

### 2.4 环境变量（`.env.example` 必含键名）

```bash
# 服务
SERVER_PORT=8080
SPRING_PROFILES_ACTIVE=local

# MySQL
MYSQL_HOST=127.0.0.1
MYSQL_PORT=3306
MYSQL_DB=jcyunpu
MYSQL_USER=jcyunpu
MYSQL_PASSWORD=change_me

# Redis
REDIS_HOST=127.0.0.1
REDIS_PORT=6379
REDIS_PASSWORD=

# RabbitMQ
RABBITMQ_HOST=127.0.0.1
RABBITMQ_PORT=5672
RABBITMQ_USER=guest
RABBITMQ_PASSWORD=guest

# MinIO / OSS
STORAGE_TYPE=minio
MINIO_ENDPOINT=http://127.0.0.1:9000
MINIO_ACCESS_KEY=minioadmin
MINIO_SECRET_KEY=minioadmin
MINIO_BUCKET=jcyunpu
# OSS_* 仅非 local 使用

# JWT
JWT_ACCESS_SECRET=change_me_access
JWT_REFRESH_SECRET=change_me_refresh
JWT_ACCESS_TTL_SECONDS=7200
JWT_REFRESH_TTL_SECONDS=604800

# 短信 / 支付
SMS_MOCK_ENABLED=true
SMS_MOCK_CODE=123456
PAYMENT_MOCK_ENABLED=true
```

### 2.5 工程约束

- Java **17**、Spring Boot **3.x**、MyBatis-Plus、RabbitMQ、Maven（架构已冻结）。  
- Schema **仅 Flyway**。  
- 对外 API 与 [`家传云谱·OpenAPI接口目录草案_v0.1.md`](./家传云谱·OpenAPI接口目录草案_v0.1.md) P0 五域对账。  
- 统一响应与分页遵守根目录《必读文档》。

## 3. Docker Compose 服务名（建议）

| 服务名 | 镜像建议 | 端口 |
|--------|----------|------|
| `mysql` | mysql:8.0 | 3306 |
| `redis` | redis:7 | 6379 |
| `rabbitmq` | rabbitmq:3-management | 5672 / 15672 |
| `minio` | minio/minio | 9000 / 9001 |

开仓时提交可运行的 `docker-compose.yml`；README 写清 `docker compose up -d` 与启动顺序。

## 4. 开仓首期交付顺序（提醒）

1. 仓库骨架 + Compose + `.env.example` + Flyway V1（按数据库大纲）
