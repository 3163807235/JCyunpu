# 家传云谱·数字管理平台（前端）

基于 **[Art Design Pro](https://github.com/Daymychen/art-design-pro)（MIT）** 改造的管理后台前端。

## 开源说明

- 上游模板：[Art Design Pro](https://github.com/Daymychen/art-design-pro)
- 上游许可证：MIT
- 本仓库许可证：见 [LICENSE](./LICENSE)（保留 MIT，并注明基于 Art Design Pro 改造）

在 UI、文案与工程标识上已切换为「家传云谱」品牌；底层能力仍来源于上游模板的开源实现。

## 技术栈

- Vue 3、TypeScript、Vite、Element Plus、Pinia、Vue Router、Tailwind CSS v4

## 快速开始

```bash
pnpm install
pnpm dev
```

构建：

```bash
pnpm build
```
