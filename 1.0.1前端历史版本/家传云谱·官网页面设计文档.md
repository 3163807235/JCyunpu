## 一、设计目标与定位

### 1.1 官网核心目标

家传云谱官网承担三大核心职能：

- **品牌认知**：传递"数字化修谱 SaaS 平台"的产品定位，建立专业、可信、有温度的品牌形象
- **线索转化**：引导目标用户注册试用，完成从访客到注册用户的转化
- **价值教育**：清晰展示产品核心功能与价值，降低用户决策门槛

### 1.2 目标访客画像

| 访客类型 | 核心诉求 | 关注重点 | 转化路径 |
|----------|----------|----------|----------|
| **家族修谱发起人** | 找到简单好用的修谱工具，替代传统手工方式 | 操作难度、版式专业性、价格 | 浏览首页 → 功能介绍 → 注册试用 |
| **族谱主编/负责人** | 评估产品是否能满足专业修谱需求 | 协作能力、数据安全、排版质量、续修支持 | 功能详情 → 案例展示 → 联系咨询 |
| **文化机构/姓氏研究会** | 批量使用或合作可能性 | 企业级能力、数据安全、定制化 | 关于我们 → 企业方案 → 商务联系 |
| **普通族人** | 了解家族历史、查阅族谱 | 浏览体验、分享机制 | 浏览族谱样例 → 注册/邀请加入 |

### 1.3 设计原则

- **文化感与现代感平衡**：既有传统文化底蕴，又体现 SaaS 产品的现代、高效
- **信任优先**：通过数据安全承诺、案例展示、透明定价建立信任感
- **行动导向**：每个页面模块都有明确的 CTA（行动号召），引导用户逐步深入
- **情感连接**：唤起用户对家族、根脉的情感共鸣，而非冷冰冰的工具介绍

## 三、首页设计

### 3.1 Hero 区域

**视觉层次**：
- 主标题（H1）：让修谱从此简单，让家族记忆永续传承
- 副标题：家传云谱 —— 专业的数字化修谱 SaaS 平台，无需排版技能，即可生成符合传统规范的家谱
- 主 CTA 按钮：免费开始修谱（醒目颜色）
- 次 CTA 按钮：观看产品演示（边框按钮）
- 信任背书文案：已有 500+ 家族正在使用 / 30 天免费试用

**背景视觉**：
- 左侧：传统族谱书页的抽象化渐变背景，营造文化氛围
- 右侧：产品界面截图（族谱总览页 + 世系图），展示现代化产品形态
- 装饰元素：淡淡的垂丝图线条、印章元素

### 3.2 核心价值主张

三栏布局，每栏一个核心价值点，配图标 + 标题 + 简述：

| 价值点 | 标题 | 简述 |
|--------|------|------|
| 📝 | 降低修谱门槛 | 无需专业排版技能，结构化录入即可生成符合传统规范的谱书。支持手动录入与 Excel 批量导入，老少皆宜 |
| ✅ | 保障修谱质量 | 六步标准化流程 + 多人协作 + 质量审核机制，兼顾效率与严谨。校勘批注、疑点复核，确保内容准确 |
| 🔄 | 实现永续传承 | 版本封存 + 多期续修 + 增量编辑，让族谱代代延续。历史版本永久留存，新增内容不篡改史料 |

### 3.3 六步修谱流程

以时间轴/流程图形式展示修谱全流程，让用户直观了解产品使用路径：

```
项目启动 → 数据采集 → 内容编排 → 质量审核 → 排版定稿 → 发布归档
   ①        ②        ③        ④        ⑤        ⑥
```

每一步配图标 + 步骤名 + 一句话说明。底部补充：
- 标准模式：五步成谱，仪式感拉满
- 简易模式：快捷成谱，5 步跳过会审，适合个人和小家族

### 3.4 核心功能模块

分 6 个功能卡片，2 行 × 3 列布局，每个卡片含图标 + 功能名 + 简述 + "了解更多"链接：

1. **人物与世系管理** —— 结构化录入人物信息，自动生成世系图，支持父子、配偶、出继等多种亲属关系
2. **多人协作修谱** —— 邀请房头采编分工录入，校勘员专项审核，角色权限清晰，协作高效有序
3. **智能排版输出** —— 支持牒记式、苏式等多种传统版式，一键生成印刷级 PDF，专业规范
4. **版本快照归档** —— 发布即封存，历史版本只读不可篡改，支持多期续修，增量增补
5. **家族文化记录** —— 家规家训、家族大事记、姓氏源流、堂号起源，完整记录家族文化
6. **数据安全保障** —— 回收站 + 软删除二级机制，用户数据自主权，平台永不主动删除

### 3.5 版式展示区

展示产品支持的传统谱书版式，配样例预览图：

- **牒记式** —— 以人物传记条目为主体，按世系排列，清晰易读
- **苏式垂丝** —— 苏洵创立的经典谱式，世代为经、父子为纬，垂丝连线一目了然
- **欧式分栏** —— 五世一提，分栏排列，便于查阅（V1.5 上线）
- **宝塔式** —— 自上而下宝塔形世系图，直观展现家族分支（V1.5 上线）

每个版式配小预览图 + 名称 + 适用场景说明。

## 四、产品功能页设计

### 4.1 页面结构

- 顶部 Hero：一句话介绍 + 功能导航 Tab
- 各功能模块详情（每个模块一个 Section）
- 底部 CTA

### 4.2 各功能模块详情

每个功能模块采用"左文右图"或"上文下图"的布局，包含：

- 功能标题
- 功能价值描述（2-3 句话）
- 核心特性列表（3-5 个要点）
- 产品界面截图 / 示意图

#### 数据采集模块
- 手动新增人物：讳、字、号、世代、生卒、籍贯、事迹等完整字段
- Excel 批量导入：下载模板 → 填写 → 上传 → 自动校验 → 一键导入
- 亲属关系管理：父子、配偶、出继、嗣子等核心关系，可视化拖拽
- 附件上传：人物照片、老谱扫描件、墓碑照等，支持多种格式

#### 协作修谱模块
- 角色权限：拥有者、主编、采编、校勘、只读，各司其职
- 任务分工：按房头分配采编范围，进度一目了然
- 编辑锁机制：单人独占编辑，防止数据冲突
- 校勘批注：疑点标注、整改意见、复核通过，全流程可追溯

#### 智能排版模块
- 多版式支持：牒记式、苏式、欧式、宝塔式，按需选择
- 排版参数可调：字号、行距、页边距、页眉页脚等
- 实时预览：所见即所得，调整后即时预览效果
- 印刷级 PDF：高分辨率输出，可直接交付印刷厂

#### 版本管理模块
- 版本快照：发布归档时全量数据封存，永久只读
- 多期续修：基于上一版增量增补，不篡改历史数据
- 版本对比：不同版本间差异一目了然
- 续修台账：清晰记录每期修谱的时间、人员、变更摘要

#### 家族文化模块
- 家规家训：逐条录入，分类管理
- 家族大事记：按时间线记录家族重要事件
- 姓氏源流：追溯姓氏起源与迁徙历史
- 堂号起源：记录堂号来历与典故
- 家族相册：珍藏家族老照片，标注人物与故事

#### 数据安全模块
- 回收站机制：删除数据 30 天可恢复
- 软删除追溯：彻底删除后仍保留后台审计记录
- 用户数据自主权：平台永不主动删除用户数据
- 数据加密传输：HTTPS 全链路加密
- 定期备份：多重数据备份，确保不丢失

## 九、视觉设计规范

### 9.1 色彩体系

**主色**：
- 品牌主色：深棕红色 `#8B2500`（传统印谱朱红的现代演绎，象征传承与庄重）
- 品牌辅色：米金色 `#C9A961`（象征家谱的泛黄纸张质感）

**中性色**：
- 标题文字：深灰 `#1A1A1A`
- 正文文字：中灰 `#4A4A4A`
- 辅助文字：浅灰 `#8A8A8A`
- 分割线 / 边框：极浅灰 `#EAEAEA`
- 页面背景：米白 `#FAF8F5`（略带暖调的白，呼应纸张感）

**功能色**：
- 成功 / 通过：绿色 `#2E8B57`
- 警告 / 待处理：橙色 `#E67E22`
- 错误 / 删除：红色 `#C0392B`
- 信息 / 链接：蓝色 `#2980B9`

### 9.2 字体规范

**中文字体**：
- 标题：思源宋体 / Noto Serif SC（体现文化感）
- 正文：思源黑体 / Noto Sans SC（保证可读性）
- 数字 / 英文：Inter 或系统无衬线字体

**字号层级**：
- H1：36-48px（桌面端）/ 28-32px（移动端）
- H2：28-32px / 24px
- H3：22-24px / 20px
- 正文：16px / 15px
- 辅助文字：14px
- 小字说明：12px

### 9.3 设计元素

**装饰元素**：
- 垂丝图线条抽象化（用于背景、分隔线）
- 印章元素（用于认证、品质标识）
- 传统书页边角纹样
- 淡色宣纸纹理背景

**图标风格**：
- 线性图标为主，2px 线条
- 圆角处理，柔和不生硬
- 关键图标可加入传统文化元素细节

**按钮样式**：
- 主按钮：品牌主色填充 + 白色文字 + 圆角 6px
- 次按钮：边框 + 品牌主色文字 + 圆角 6px
- 文字按钮：品牌主色文字，无背景无边框
- Hover 状态：轻微加深 / 阴影变化

### 9.4 响应式断点

- 桌面端：≥ 1200px
- 平板端：768px - 1199px
- 移动端：< 768px

移动端适配要点：
- 导航改为汉堡菜单

## 十、交互与动效

### 10.1 微交互

- 按钮 Hover：颜色渐变 + 轻微上浮
- 卡片 Hover：阴影加深 + 轻微上浮
- 导航菜单：下划线平滑滑动
- 表单输入：聚焦时边框变色 + 标签上移
- 加载状态：骨架屏 + 渐显

### 10.2 滚动动效

- 元素进入视口时渐显上浮
- 进度条 / 数字从 0 滚动到目标值
- 长页面自动高亮当前所在章节（侧边导航）

### 10.3 关键页面动效

- Hero 区域：主标题逐字显现 / 背景缓慢平移
- 流程图：线条从左到右绘制动画
- 定价卡片：推荐项默认高亮，其他项 Hover 时轻微放大
- FAQ 折叠：平滑展开 / 收起，箭头旋转 180°

## 十一、SEO 与性能

### 11.1 SEO 优化

- 每个页面独立设置 title、description、keywords
- 语义化 HTML 结构（H1-H6、nav、main、section、footer）
- 图片添加 alt 属性，包含关键词
- 页面 URL 结构清晰：/features/data-collection
- 面包屑导航（SEO 友好）
- 结构化数据（Schema.org）：Organization、FAQ、Product
- sitemap.xml 自动生成
- robots.txt 配置
- 页面加载速度优化（核心 Web 指标）

### 11.2 性能要求

- 首屏加载时间 ≤ 2s（4G 网络）
- LCP（最大内容绘制）≤ 2.5s
- FID（首次输入延迟）≤ 100ms
- CLS（累计布局偏移）≤ 0.1
- 图片懒加载
- 静态资源 CDN 加速
- CSS / JS 压缩与合并

## 十二、技术实现建议

### 12.1 技术栈选型

- **框架**：Next.js（React SSR，利于 SEO）或 Nuxt.js（Vue SSR）
- **样式**：Tailwind CSS + CSS Modules
- **动画**：Framer Motion 或 GSAP
- **图标**：React Icons / 自定义 SVG 图标库
- **CMS**：Contentful / Strapi / 自建管理后台（用于案例、FAQ、帮助文章的内容管理）

### 12.2 部署建议

- 前端静态部署：Vercel / Netlify / 阿里云 OSS + CDN
- 图片资源：对象存储 + CDN + 图片自动裁剪压缩
- 域名与 SSL：独立域名，全站 HTTPS
