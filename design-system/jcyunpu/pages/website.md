# Website Page Overrides

> **PROJECT:** 家传云谱  
> **Direction:** Ink & Jade Archive（墨色 + 青绿数字典藏）

覆盖 MASTER 的页面规则：

## 视觉

- 背景用冷灰白 `#F3F5F7`，禁止米黄纸 `#F7F2E7` / 奶油风
- 主色为墨色按钮 + 青绿强调，禁止朱砂/赤陶主色与大面积烫金
- 按钮圆角 8–10px，禁止 `rounded-full` 胶囊堆叠
- 字体：正文 Manrope；中文品牌/标题可用 Noto Serif SC；避免 Inter/Roboto

## Hero

- 品牌「家传云谱」hero 级展示
- 首屏：品牌 + 主标题 + 一句支撑 + CTA + 全幅主视觉
- 统计不进首屏（TrustBar）
- 主视觉用冷静的谱系结构线，不做古风装饰框

## Motion

- 轻量 reveal；`prefers-reduced-motion` 关闭位移
